# D-0017 — Que devient tools/README.md dans l'adoption du socle ?

> date : 2026-11-17 · forme : séance

## Question posée

Posé à Théo dans la conversation du 17 nov. 2026 : `tools/README.md` pèse 1,56 Mo, dont 31 Ko de documentation des outils ; le reste est fait de récits de verdicts, de protocoles et d'états « en vol » (du journal, au sens du socle), d'une feuille de route résiduelle et du registre des réglages ouverts. Le découpage validé le 12 nov. l'avait laissé hors de l'adoption. Trois options lui étaient proposées, la recommandation de l'agent étant `B` :

- `A` — le laisser tel quel ;
- `B` — ne retirer que la feuille de route résiduelle, les phases de « La file », et garder le reste ;
- `C` — le scinder : la documentation des outils reste, les récits de verdicts et l'histoire partent au journal, en plusieurs lots, chaque renvoi suivi.
