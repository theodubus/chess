# ADR-0025 — L'AGPL figée dans tous les cas : une contribution extérieure sans CLA est acceptable

> statut : acceptée · date : 2026-09-14 · lu : decisions@2c306920

## Contexte

Décision de Théo portée par la rubrique « 07 — Risques, limites et questions ouvertes » du carnet de bord, dans ses questions ouvertes non techniques, recopiée telle quelle dans la mémoire. Elle complète ADR-0007@a83563c3, le choix de l'AGPL-3.0.

## Décision

**[Décision utilisateur]** **Tranché le 14 sept. 2026 : l'AGPL est figée dans tous les cas.** Théo : « je vais figer l'agpl dans tous les cas, si ça permet d'améliorer le produit alors très bien. » Une contribution extérieure sans CLA est donc acceptable — la conséquence est assumée, pas subie. <s>**Contributions extérieures** — ouvrir le dépôt aux contributions sans CLA fige définitivement la licence AGPL-3.0. À décider avant d'accepter la première.</s>

## Conséquences

Le carnet n'en écrivait pas à part : elles sont dans la décision.
