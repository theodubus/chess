> statut : ouvert · origine : J-2026-11-12-H · pour : humain · priorité : haute · lu : backlog@56228da4

après avoir d'abord demandé un tri. L'agent l'a lu comme « public tel
quel, sans tri » (D-0006). Cette lecture retire le dernier arrêt avant
une publication qui ne se défait pas : le dépôt est public, et un
historique git ne s'efface pas. Le journal du carnet ne se pose pas dans
la mémoire avant cette confirmation (B-0006).

le tri retire.
